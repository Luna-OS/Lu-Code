# luCode 1.1.3

„Request timed out“ beendet keinen Lauf mehr: Reißt die Verbindung zum Modell ab, versucht luCode es von selbst noch einmal.

## Behoben

- **„Request timed out“ mitten im Chat** – Kam eine Anfrage des Agenten an das Modell nicht durch (Zeitüberschreitung, abgerissene Verbindung, kurzer Serverfehler), brach der Lauf mit einer roten Fehlerbox ab. Danach musste man die Nachricht neu schicken. Jetzt startet luCode den Agenten im selben Lauf neu, nach 5, 30 und 90 Sekunden, höchstens dreimal. Er macht genau dort weiter, wo er unterbrochen wurde. Die Nachricht und angehängte Bilder gehen dabei nicht verloren und werden nicht doppelt geschickt. Im Chat steht statt der Fehlerbox „Verbindung zum Modell unterbrochen – neuer Versuch 1 von 3“. „Stopp“ oder eine neue Nachricht beenden das Warten sofort.
- **Zeitlimit für Claude Code** – Claude Code wartet jetzt bis zu 30 statt 10 Minuten auf eine Antwort. Das hilft bei langen Antworten und wenn ein Proxy oder Virenscanner Antworten zurückhält. Eigene Werte in den Einstellungen des Kontos (`settings.json`, `env`) gelten weiter.

## Installieren (Windows x64)

**Von 1.1.2:** In der App auf „Aktualisieren“ klicken – Daten, Konten und Chats bleiben.

**Von 1.1.1, 1.1.0 oder 1.0.0: bitte einmal von Hand aktualisieren.** **luCode-1.1.3-Setup.exe** ausführen – Daten, Konten und Chats bleiben. Wer die ZIP nutzt: entpacken und `luCode.exe` ersetzen. Der Updater dieser Versionen hat einen Fehler und findet in diesem Release absichtlich keine Datei für sich (siehe 1.1.2).

**Neu:** **luCode-1.1.3-Setup.exe** ausführen (Installer je Benutzer, ohne Administratorrechte) – oder **luCode-1.1.3-x64.zip** entpacken und `luCode.exe` starten. Windows SmartScreen fragt beim ersten Start evtl. nach (die App ist nicht signiert): *Weitere Informationen* → *Trotzdem ausführen*.

---

**English:** "Request timed out" no longer ends a run. When an agent's request to the model does not get through (timeout, dropped connection, brief server error), luCode now restarts the agent in the same run after 5, 30 and 90 seconds, at most three times. The agent continues exactly where it was interrupted. Your message and attached images are kept and not sent twice. The chat shows "Connection to the model interrupted – retrying (1 of 3)" instead of the error box; *Stop* or a new message ends the wait at once. Claude Code now waits up to 30 minutes for an answer instead of 10, which helps with long answers and with proxies or virus scanners that hold responses back; your own values in the account's `settings.json` (`env`) still apply. **Coming from 1.1.2:** click *Update* in the app. **Coming from 1.1.1, 1.1.0 or 1.0.0, please update once by hand:** run **luCode-1.1.3-Setup.exe** (your data stays).
